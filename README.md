# POISE // 破防之隙

单文件 HTML5 Canvas 动作肉鸽。削韧破防、海克斯改写规则、多模式无尽推进。

**Developer: [IDKURLOVE](https://github.com/IDKURLOVE)**  
**Supported by: MiM-X-Pro-Preview**

## 玩法

### 核心循环
敌人不是血包，是「锁」。用轻击凑韧性、重击砸破防；破防后伤害 ×1.5，趁窗口输出。

1. **读招** — 前摇双通道预告（亮色填充 + 轮廓脉冲 + 方向锥）
2. **走位 / 闪避** — `Space` 无敌帧 0.18s，冷却 0.6s
3. **输出** — 轻击叠削韧，重击重创；贴脸轻击削韧更高
4. **收割** — 破防窗口内爆发，清层进下一层

### 操作
| 键 | 作用 |
|----|------|
| WASD | 移动 |
| Space | 闪避 |
| J / 左键 | 轻击 |
| K / 右键 | 重击（右键不弹菜单） |
| Esc | 暂停 / 放弃本局 |
| R | 重开 |
| M | 模式大厅 |
| A | 成就 |
| F1 | 埋点调试 |

### 角色
| 角色 | 定位 |
|------|------|
| **刃** | 近战 · 贴脸削韧 · 高生命 |
| **弦** | 远程 · 移动射击 · 弹丸海克斯可改写数量/体积/追踪 |
| **盾** | 坦克 · 超高生命 · 闪避后短窗格挡减伤 70% |

### 模式
| 模式 | 玩法 |
|------|------|
| 无尽 | 主模式，每 5 层出口结算 ◆ |
| 战役 | 12 层 + Boss，通关解锁竞技场 |
| Boss 连战 | 精英车轮 |
| 竞技场 | 90 秒生存 |
| 挑战之书 | 12 条固定规则 / 种子 |
| 自定义 | 修饰器自由堆叠 |
| 每日种子 | 当日同种子 + 本地排行 |

### 成长
- **升级**：击杀得 XP；每级 +生命、+伤害；每 2 级可选海克斯
- **海克斯**：银（条件）/ 金（打法）/ 彩（结构质变）；可重复获取升级
- **局外**：◆ 买解锁（四选一 / 治疗预算 / 开局银章）
- **成就**：28 条
- **攀升**：标题 `,` / `.` 调整难度层级

## 怎么打开

### 桌面程序（推荐）
双击 **桌面 `POISE`**，或：

- `POISE-Start.vbs` — 无黑框独立窗口
- `POISE-Start.bat` — 同上

使用 Edge/Chrome `--app` 模式。

### 浏览器
直接打开 `index.html`。
